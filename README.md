## 🧭 Overview & 15 Dedicated Routes

This platform features 15 dedicated engineering pages, an interactive drawer navigation system, a `Ctrl+K` command search palette, and decoupled data models:

### 1. MAIN
- **`/` (Home)** — Identity hero, live focus dashboard ("Currently Pursuing"), interactive 4 domain cards, capability grid, vector query execution pattern diagram, and selected builds.
- **`/about` (About Me)** — Technical journey, B.Tech CST degree from Presidency University Bangalore, engineering principles, "Why Four Domains?", and the "Learn → Build → Break → Learn" loop.

### 2. DOMAINS
- **`/domains/ai-ml` (AI/ML Engineering)** — RAG vector pipelines, dense Sentence-Transformers (384-dim), FAISS/ChromaDB indexing, and local LLM inference via Ollama.
- **`/domains/software-web` (Software & Web Development)** — Full-stack web architecture, React 19, Next.js App Router, TypeScript, FastAPI REST backends, and featured build *Social Story Studio*.
- **`/domains/data-science` (Data Science & Analytics)** — Exploratory data analysis, gradient boosting CTR modeling, target encoding, and 100K+ candidate vector corpus metrics.
- **`/domains/cybersecurity` (Cybersecurity)** — Defensive security fundamentals, STRIDE threat modeling workflows, OWASP Top 10 mitigation patterns, and AI risk defense.

### 3. WORKS
- **`/projects` (Projects)** — Interactive Project Explorer with instant search and category filtering across *All, AI/ML, Software & Web, Data Science, Cybersecurity, GenAI & RAG*.
- **`/hackathons` (Hackathons & Competitions)** — Technical competitive builds, sprint outcomes, and build repositories.
- **`/research` (Research Works)** — Empirical evaluations of sentence embeddings, local LLM performance on 128 GB memory clusters, and feature flag middleware latency.
- **`/insights` (Engineering Insights)** — Quantitative scale metrics, focus distribution, and Before vs. After engineering trade-off case studies.

### 4. CAREER
- **`/toolkit` (My Toolkit)** — Grouped inventory of programming languages, AI frameworks, databases, and developer tools with proficiency levels.
- **`/learning` (Learning & Certifications)** — Verified course examination scores from Meta (*JavaScript 95.33%*, *Version Control 88.12%*) and IBM (*GenAI 95.23%*, *RAG 85.71%*, *Vector DBs 100%*).
- **`/experience` (Experience Timeline)** — Visual vertical milestone timeline detailing degree and hands-on project milestones.
- **`/resume` (Resume)** — Recruiter-friendly view with `@media print` support and save-to-PDF functionality.
- **`/contact` (Contact)** — Inquiry reason selector (*Hire Me, Collaborate, Have an Idea, Discuss AI/ML, Research, Just Say Hello*), project scope inputs, and copy email interface.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Sankrityayana/Suraj-Laxman-Shanbhag.git
cd Suraj-Laxman-Shanbhag
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Visit `http://localhost:3000` to view the website.

### 4. Build for production
```bash
npm run build
npm run start
```
